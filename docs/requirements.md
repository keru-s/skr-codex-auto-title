# 首次公开发布要求

1. 名称统一为 skr-codex-auto-title，保持个人品牌前缀。
2. 提供全局安装：一次安装，处理安装后新建的各项目主对话。
3. 提供项目安装：只影响安装项目及其子目录。
4. 全局安装后能单独关闭、启用和查看某项目的开关；其他项目不受影响，开关更新后保留。
5. 两种安装并存时项目安装优先；项目安装停用不回退全局；全局项目关闭规则约束两种范围。
6. 同一会话首次完成后只命名一次。切换范围保留已完成结果与待重试标题，避免重复调用和改名。
7. 安装、更新与卸载保留其他 Hook 和用户设置。失败回滚并保留私人备份。
8. 首次开源不涉及旧公开版本迁移；提供未来更新入口，保留配置、启用时间、开关和记录。
9. 技能目录可单独复制运行，文档明确两种安装、管理和隐私位置。测试与分发不包含私人数据。
10. 完成自动检查与实际 CLI 隔离安装检查，由独立审查负责人复核后再准备公开发布。不得将模拟测试称为桌面自动触发成功。

11. 轻量命名不传完整历史，选中正文加模块参考最多3500字符，保留答复结尾和未完成提醒；长首条请求不永久阻断命名。
12. 失败不当轮连续重试，下一轮继续；已有标题的重试不得依赖新内容。未生成标题时优先最新答复，模型结果等待25秒，总后台连接60秒，Hook75秒。
13. README 给出可复制的全局、项目和技能安装流程；公开发布到用户指定的 keru-s/skr-codex-auto-title 仓库。
