# 发布检查与限制

首次公开发布，名称为 skr-codex-auto-title；不存在公开旧版本迁移要求。

## 发布检查

- 技能目录可单独复制，安装器与运行脚本随目录分发。
- 根目录安装入口与技能入口使用同一实现。
- 安装保留现有 Hook 和用户设置，失败时恢复已管理的改动。
- 今后更新使用 upgrade，保留命名记录、模型、项目术语与启用时间；测试覆盖更新和恢复行为。
- 项目状态与私人会话证据排除在版本管理之外。

## 当前限制

仅支持 macOS/Linux、Python 3.11+ ，支持全局与项目级 Hook。将技能放到个人目录仅提供安装入口，安装范围由 --scope 决定。

标题主要为中文；首次完成前的人工标题可能被覆盖。模型判断可能出错。关闭会话可能取消尚未结束的工作，长输入会跳过自动命名。项目或 Python/CLI 位置变化后需重新核对安装。

测试和真实验证的范围见 [验证说明](validation.md)。
