## 桌面自动触发

通过桌面应用提供的会话入口新建测试对话并发送普通业务请求，后台由桌面原生Stop自动触发，未向Hook手工传入Stop：

- 项目安装：只追问时不标记完成；交付解释后自动命名。后续交付、归档后恢复对话，标题与成功记录保持。
- 全局和项目同时安装：项目只评估一次并成功命名，全局没有重复评估。
- 卸载项目安装后，仅全局安装自动完成文档命名，记录了目标项目专属术语来源。
- 全局下关闭单个项目：新业务交付没有产生本工具的状态或推理；重新开启后继续交付，自动命名。
- 主对话记录中没有命名指令注入、命名子代理、主模型改名调用或自动续跑。标题由独立的桌面会话读回确认。

私人对话与证据保存在公开仓库之外。测试安装和测试对话在验证结束后清理。

图形界面控制被当前环境禁止，未进行窗口点击和视觉刷新验收。上述自动触发通过桌面会话入口验证，不能等同于图形界面点击验证。实际上下文压缩尚未验证；离线检查覆盖压缩后的事件与成功状态保持。Linux与远端检查结果以对应提交的GitHub Actions为准。本地通过不代表远端通过。

模拟超时和故障验证了恢复路径，不代表制造过真实服务超时。实际模型检查和桌面自动触发均使用正常服务，没有人为制造远端错误。
