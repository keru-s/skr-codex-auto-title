# 验证范围

本项目为首次公开发布。以下记录区分已执行的检查与尚未验证的使用过程。

## 可复现检查

```sh
uv run python -m unittest discover -s tests -p 'test_*.py'
uv run python tests/check_distribution.py
uv run python tests/test_real_install.py /absolute/path/to/codex
uv run python tests/test_real_scopes.py /absolute/path/to/codex
```

前两条不需要登录或密钥；后两条使用临时项目及隔离 CODEX_HOME，不调用模型，验证安装、检查、停用、启用与卸载，以及保留已有 Hook 和设置。

## 2026-10-21 实际验证

macOS、Python 3.11.14 / 3.12.12 / 3.14.3：各 73 项离线测试通过；包含重复与并发触发、失败重试、读回恢复、独立复制技能、保留安装记录的更新、设置保留及回滚。资源、链接、语法与私人信息检查通过。

Codex CLI 0.162.1 的实际隔离安装、检查、停用、启用、卸载通过，含空格路径通过，原有 Hook 与用户设置保留。全局与项目并存、单项目开关的实际命令、更新保留开关和双范围卸载也通过。新增离线检查覆盖全局跨项目命名、单项目关闭、子目录规则、项目安装优先以及跨范围成功记录和待重试标题；新安装时间晚于会话创建时间的两个切换方向也有专门检查。

## 尚未验证

本次已调用真实模型并确认官方改名读回，但没有验证桌面原生异步触发和界面自动刷新的完整过程。Linux 和 GitHub Actions 的实际运行结果以公开仓库 Actions 记录为准；本地检查不等于远端已通过。

## 显式运行真实模型检查

以下命令会创建临时会话并使用模型额度：

```sh
uv run python tests/test_live_runtime.py --run-live --codex /absolute/path/to/codex --codex-home /absolute/path/to/codex-home --report /private/path/live-report.json
```

它向运行脚本手动传入真实 Stop 数据，验证模型判断、改名与读回；不能代替桌面自动触发检查。默认归档测试会话。仅为桌面观察使用 --keep-test-thread，观察后应归档。报告和私人运行证据应保存在公开仓库之外。

## 独立审查

独立负责人完成规范与需求审查，发现安装范围切换后既有会话可能失去处理资格的问题。修复后，负责人独立复现两个切换方向，并检查旧会话、项目关闭、排除名单和子对话限制，复核通过，无未解决的阻碍问题。结论允许进入公开仓库创建前的准备阶段，不代表尚未执行的桌面自动触发和真实模型检查已经通过。

## 轻量版验证

新增检查覆盖长首条请求不阻断、长答复保留结尾和中间未完成提醒、请求去重、模块上限、失败单次后下轮恢复、下轮使用最新答复、已有标题在无新请求及超长回复下仍能完成改名。
