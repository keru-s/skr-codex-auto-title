# 验证真实行为

需已获用户授权创建、发送任务并归档临时主对话；授权缺失时只做配置检查，报告尚未进行桌面测试。

1. 新建启用后普通主对话，完整任务先缺少必要参数，只追问。等后台 assessment.completed=false，确认标题保持。
2. 给出完整分析或文档任务并交付正文。等 done=true，核对 evidence 中临时推理线程的实际 model/effort/ephemeral、first_completed_turn 与交付回合、官方改名回执和匹配读回。再用当前桌面的原生命名/读回能力独立读取标题。观察者不代为改名或写 done。
3. 确认主对话没有 hookPrompt、额外命名用户消息、命名子代理或主模型改名工具调用。产品仍可能显示简短 hook 运行状态。
4. 再交付第二项任务，确认标题和成功状态字节保持，没有新推理。归档测试对话。

没有能验证当前界面的读回能力时，区分“官方 API 已读回”与“桌面已验证”。配置 trusted、JSON 输出或模型建议标题都不等于改名成功。恢复、压缩、并发、不同平台的验证范围分别记录。
